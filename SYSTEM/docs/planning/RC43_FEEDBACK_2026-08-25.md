This tracker consolidates hands-on RC43 feedback into public-safe engineering
work. It intentionally omits raw tester prompts, customer URLs, credentials,
secret values, and private plugin implementation details. Deterministic checks
belong in engineering evidence; only human-judgment and external-environment
checks should be copied into the Release Review plugin.

candidate must be RC45 after the focused fixes below are complete and the full
public/private image gate passes.
