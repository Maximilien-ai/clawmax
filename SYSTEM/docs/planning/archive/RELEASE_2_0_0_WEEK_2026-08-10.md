## RC37 Session Recovery Candidate

The first RC36 on-prem chat test exposed an embedded OpenClaw session conflict
that required a manual reset. RC37 carries the bounded recovery fix: chat and
workflow execution each retry once with a fresh session, the browser retains a
recovered chat session for later turns, and visible partial output is not
replayed. RC37 must repeat the full source gate and both public and authorized
combined multi-architecture image gates before replacing RC36 evidence.

## Scope Freeze

`2.0.0` ships the current public plugin host, Lifecycle, Release Review, AI
Builder/generation quality surfaces, plugin management, workspace dashboards,
partner foundations, and the separately packaged enterprise plugin suite.

The following are not Friday blockers unless validation finds a regression in
their already shipped baseline:

- autonomous score remediation or broad policy orchestration;
- production mailbox send/delete operations;
- general third-party remote frontend or unrestricted server plugin execution;
- later Activity Export destinations beyond the consent-gated reference path;
- richer Lifecycle export and new target types beyond current evidence-backed
  agents, workflows, groups, and communities;
- post-2.0 model-fit calibration and optimization learning loops.

No new product surface enters the release after Tuesday without replacing work
of equal or greater risk and receiving an explicit release decision.
