# Changelog

## 0.2.0

- Add multi-agent Lifecycle inspections with creation, model, file, and
  conversation metadata.
- Add focus and time-window filtering with a chronological fishbone timeline.
- Record dashboard-driven configuration and model changes for future audits.
- Preserve privacy by returning metadata and counts without file or conversation
  contents.

## 0.1.0

- Add the public Lifecycle plugin skeleton for agent and workflow inspection.
- Define subject, focus, time-window, archive, and notes fields using the
  generic declarative plugin contract.
- Add starter inspections for agents and workflows.
